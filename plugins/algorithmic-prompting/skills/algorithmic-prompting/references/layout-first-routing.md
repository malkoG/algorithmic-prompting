# Layout-first routing

Treat the repository layout as an index for assigning investigation, not as a prompt to comprehend implementation.

Use only:

- Repository instructions
- Directory, module, and package names
- Map-document filenames and headings
- Schema entity names
- Workspace and build boundaries
- Goal-keyword matches in those structured surfaces

Do not read implementation, tests, SDK internals, UI internals, full schemas, or complete design documents before publishing the index. Do not verify inferred ownership against code.

Stop when the layout supports plausible lane ownership and obvious explicit prerequisite edges. The coordinator answers where to investigate; detail subagents answer how the system works.
